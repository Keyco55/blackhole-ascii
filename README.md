# ascii black hole

A black hole rendered entirely in characters, with the Python that draws it
scrolling underneath. Its shadow and lensed disk are ray traced: photon paths
through the bent space are tabulated once, then the gas turns with Kepler's
law — fastest at the inner edge. Built for a phone, so it runs full bleed
inside a link preview.

Static page, no build step.

```
open index.html
```
